## 一、程式用途

本次作業使用 Python 製作兩場活動報名整理器，分別整理「桌遊體驗」與「電影欣賞」的報名名單。

程式會先移除姓名中多餘的空白，並統一轉換成小寫，再刪除重複報名的資料。接著利用集合運算找出共同參加者、只參加其中一場活動的人，以及全部不重複的參加者，最後統計人數、報名人次與活動應收費用。

## 四、個人回答

### 問題一

測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

**回答：**

因為桌遊名單中的 Amy 重複出現兩次，但實際上是同一個人，所以不能重複收費。將字串整理成 list 後，會保留原本的報名順序和重複資料，因此可以看出誰重複報名。而轉換成 set 後，雖然會失去原本的順序和重複資料，但可以確保每個人只計算一次。因此桌遊實際只有 3 位參加者，應收費用為 3 × 120＝360 元。

### 問題二

測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

**回答：**

因為測試三的桌遊和電影名單去重後完全相同，都是 Amy、Ben、Cora，所以兩個集合的交集和聯集都是這 3 個人，總不重複人數只有 3 人。但每個人都同時參加兩場活動，因此每人要計算兩次報名人次，總共是 3＋3＝6 人次。由於兩場活動的費用分開計算，桌遊是 3 × 120＝360 元，電影是 3 × 80＝240 元，所以總應收仍然是 600 元。
